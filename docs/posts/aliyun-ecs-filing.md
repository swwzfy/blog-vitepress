# 阿里云 ECS 选型与备案实录

博客之前一直跑在纯静态托管上，省心但没掌控感。今年把它搬到了阿里云自己的服务器上，域名、备案、Nginx 一步步趟过来，中间在备案这关被卡了一次，教训深刻。这篇把选型和备案这段最折腾的部分记下来，给同样想在国内上线的朋友一个参考。

<!-- more -->

## 一、为什么要国内服务器

先把选择说清楚：**国内服务器必须备案，海外服务器免备案**。这个前提决定了一切后续。

我当时在两难：

| 方案 | 优点 | 缺点 |
|------|------|------|
| 海外 VPS（免备案） | 不用折腾备案，上线快 | 国内访问慢、线路不稳 |
| 国内服务器 + 备案 | 访问快、稳定、合规 | 要花时间备案，内容受限 |

我的读者主要在国内，博客又是长期经营的东西，慢和抖都忍不了，所以选了国内 + 备案这条路。如果你只是临时放个 demo，海外更省事。

## 二、选型：轻量应用服务器 vs ECS

阿里云有两类常见选择，别一上来就买 ECS：

- **轻量应用服务器（Lighthouse）**：预装好系统 + 应用镜像，便宜、省心，适合个人博客这种低负载场景。
- **ECS（弹性云服务器）**：灵活、可扩展、能装任意镜像，但配置项多、价格也更贵。

对个人博客来说，**轻量应用服务器基本是首选**——2 核 2G 起步，装个 Nginx 跑静态站绰绰有余。ECS 等哪天真的要做负载均衡、多实例再说。

> 我的实际选择：国内 2 核 2G，新账号首年 68 元/年。原则就一条：**先买最便宜的，不够再加**，云服务器升配比降配容易。

## 三、备案：流程本身不复杂，坑在"内容范围"

选型和购买都是半小时的事，真正折腾的是备案。流程大致四步：

1. 域名实名认证（域名持有者得是你本人）
2. 在阿里云备案系统提交网站信息（服务器 + 域名绑定）
3. 身份核验（现在主要是 App 人脸核验）
4. 管局审核，通过后拿到 ICP 备案号，挂到网站底部

各省管局审核时长不一样，快的几天，慢的两三周，做好心理准备。

### 踩坑：个人备案不是"想放什么放什么"

这一步是我被卡的根源。很多人以为个人备案就是走个过场，其实**个人 ICP 备案对网站内容有明确边界**。

按阿里云的口径，个人备案的网站可展示内容基本等同于"**个人内容分享**"——你自己的文章、作品、记录。而**访客即时公开的 UGC**，比如评论、留言板、发帖、注册，会被归入「论坛 / 社区」一类，个人备案做不了。

我一开始图省事，给博客加了评论功能，结果备案卡住了。后来撤掉评论、把网站内容收敛成纯个人分享（文章、动态、友链都是自己可控或审核后展示的），才顺利通过。

**教训一句话**：个人备案 = 站长单向输出。想要访客直接发内容的功能，要么升级主体资质，要么就别做。

## 四、上线

备案通过后，剩下的就是常规操作：

- 域名 DNS 解析到服务器 IP
- 装 Nginx，把站点目录指向构建产物
- 申请 SSL 证书，配 HTTPS

这些在上一篇《从零搭建个人服务器》里已经写过，这里不重复。值得说的是：**备案号和 SSL 都别忘**——备案号要挂在页面底部（监管要求），HTTPS 是基本礼仪。

## 五、花费（参考）

服务器和域名都购自阿里云，都是赶上新账号 / 活动优惠买的。

| 项目 | 价格 | 说明 |
|------|------|------|
| 服务器（2 核 2G） | 68 元/年 | 新账号首年优惠 |
| 域名 | 77 元 | 活动优惠购入 |

加起来一年一百多块，对个人博客来说几乎可以忽略。注意这是首年优惠价，**续费价格要以阿里云官网当时的标价为准**，快到期时留意一下。

## 几点总结

1. **国内上线，备案是绕不过的第一关**，先想清楚内容边界再动手，别等被卡了再改。
2. **选型从便宜的开始**，个人博客用轻量服务器就够，别为"以后可能"多花钱。
3. **备案的坑不在流程，在内容范围**——个人备案等于个人分享，别加访客公开 UGC。

> 服务器是你在数字世界的家，备案是它的户口本。花点时间把两样都办对，后面才睡得安稳。
